# Support-genie
Enterprise AI support resolution agent built using:

* LangChain
* OpenAI
* RAG
* Tool Calling
* Conversational Memory
* Feedback Adaptation
* LangSmith

## Features

* Retrieval-Augmented Generation
* Tool Calling
* Conversational Memory
* Safety Guardrails
* Feedback Learning
* LangSmith Tracing

## Installation

pip install -r requirements.txt

## Run

Open:
capstone_project.ipynb

Run all notebook cells.

## Example Queries

* Where is order 1001?
* What is your refund policy?
* Can I get a refund after 45 days?
* I want to report fraud
* Can I sue you for late delivery?
* Can i delete my account?

## Safety Features

* Unsafe request refusal
* Escalation logic
* PII-safe logging
* Runtime error handling
